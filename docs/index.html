Reasoning by Analogy
arXiv · ●●●○○ Significant
›

This research proposes a post-training framework called Retrieval-Augmented Reinforcement Fine-Tuning (RA-RFT) that teaches language models to reason by analogy. RA-RFT uses a retriever to rank contexts by expected reasoning benefit and fine-tunes the policy model via reinforcement fine-tuning methods with retrieved analogous demonstrations.

This matters because it enables language models to learn complex reasoning tasks by leveraging analogous examples, which can improve their performance on tasks that require abstract thinking and problem-solving.

SpatialClaw Improves Spatial Reasoning
arXiv · ●●●○○ Significant
›

SpatialClaw is a training-free framework for spatial reasoning that uses code as the action interface, allowing for more flexible and open-ended 3D/4D spatial reasoning. It addresses the limitations of existing spatial agents that rely on single-pass code execution or structured tool-call interfaces.

SpatialClaw's flexible action interface can improve the ability of vision-language models to reason about complex spatial relationships, which is crucial for tasks like robotics and 3D modeling.
